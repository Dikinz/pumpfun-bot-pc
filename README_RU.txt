v0.7.101.5 — запись диагностики в фоновом потоке, атомарный старт ветки, настольное приложение 16_DESKTOP (02.11.2026)

Читайте RELEASE_NOTES_v101.md, особенно продолжение старой кампании с открытым остатком.
Новая папка → 01_INSTALL → 02_SETTINGS → при продолжении перенос целиком остановленной app/data → полный 04_CHECK.
14_RPC_STATUS — ограниченное восстановление известного отказа + один read-only mainnet RPC; смотреть READY и рост started.
03_START — обычный PAPER.
15_PAPER_FAULT_TEST — два часа обычного PAPER, инъекция отказа чтения приоритета на 10 с через час, штатная остановка в конце. Ранний STOP делает тест незавершённым.
05_RESULTS — после остановки. Старую папку/архивы не удалять, control_failed вручную не удалять.
API-ключи — только через настройки, private key не вводить. Порт панели 127.0.0.1:8188. Только PAPER.

16_DESKTOP — окно Windows для PAPER-бота: терминал, значок в трее, запуск и корректная остановка без консоли (подробно: docs/DESKTOP_APP_USER_RU.md).
Нужны Microsoft Edge WebView2 Runtime и путь к папке бота не длиннее 150 символов. Первый запуск 16_DESKTOP создаёт .venv-ui (нужен интернет).
Крестик при работающем боте сворачивает окно в трей; «Выйти из окна» бота не останавливает. Остановка — «Бот → Остановить…», как Ctrl+C в 03_START.
Останавливайте бота до выхода из Windows: при «Всё равно завершить» Windows прерывает движок, дальше 09_RECOVERY_CHECK и 05_RESULTS.
Красное «бот работает без управляющего процесса»: перезагрузите ПК, затем 09_RECOVERY_CHECK. «Бот остановился сам (код N)»: журнал, 05_RESULTS, 09_RECOVERY_CHECK.
Обновление в той же папке: остановить бота → 08_PRESERVE_DATA → установщик или ZIP по порядку из docs/DESKTOP_APP_USER_RU.md; app/data, app/.env и results сохраняются.
