# Текущая цель — диагностический счётчик не блокирует обработку рынка

| Проверка | Критерий |
| --- | --- |
| Тик | Только ограниченное накопление candidate/clock-shadow counters в памяти |
| Запись | Отдельный поток, пакет, свой connection; измерены queue/BEGIN/write/commit |
| Нагрузка | До 512 различных ключей суммарно; переполнение/ошибки явные |
| Учёт | accepted, committed, dropped, unflushed; счётчики не финансовая когорта |
| Остановка | Финальное состояние writer каждой ветки, отсутствие скрытого sync fallback |
| Финансы | Прежняя атомарность BUY/SELL, ledger, баланса и освобождения слотов |

Короткий тест 3–5 полных пар или 20–30 минут. Порог watchdog, стратегия и часы
не меняются. Длительный тест до 100 закрытий пока не нужен. После проверки
повторно оценить источник оставшихся задержек записи, если они появятся.
