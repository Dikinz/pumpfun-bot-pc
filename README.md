# PUMPFUN BOT v0.7.101.2 (PAPER)

Самостоятельная PAPER-сборка: реальные сделки не отправляются, ключи подписи не нужны.
Актуальные инструкции: README_RU.txt (русский) и README.txt (English).
Изменения версии: RELEASE_NOTES_v1012.md, RELEASE_NOTES_v1011.md и RELEASE_NOTES_v101.md. Панель только для чтения: http://127.0.0.1:8188/terminal. Дорожная карта: ROADMAP.md.

## Порядок
1. Новая папка, 01_INSTALL.bat, затем 02_SETTINGS.bat (API/RPC заново; private key не вводить).
2. При продолжении кампании — перенос целиком остановленной app/data (RELEASE_NOTES_v101.md).
3. Полный 04_CHECK.bat; затем 14_RPC_STATUS.bat при штатно остановленном боте.
4. 03_START.bat — обычный PAPER; 15_PAPER_FAULT_TEST.bat — двухчасовой контролируемый PAPER.
5. 05_RESULTS.bat — только после штатной остановки.

Панель: http://127.0.0.1:8188. Перед запуском BAT проверяют SHA-256 файлов по BUILD_MANIFEST.json;
копия из git с переводом строк CRLF принимается, любое другое изменение блокирует запуск.
Пороги стратегии, лимиты RPC и правила свежести этой сборкой не менялись.
Прибыльность, реальное исполнение и многочасовая устойчивость у провайдера не подтверждены.
